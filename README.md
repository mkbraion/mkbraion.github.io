Portfólio de desenvolvimento full-stack com projetos web e mobile, formação, certificados e contato profissional.

## Implementação

- HTML, CSS e JavaScript, sem etapa de compilação ou framework de interface.
- Navegação por seções, layout responsivo e suporte a preferência por movimento reduzido.
- Formulário integrado ao FormSubmit e links para WhatsApp, GitHub e LinkedIn.
- Google tag para anúncios e evento de conversão no contato.

## Visualização e publicação

Abra `index.html` no navegador para consultar o conteúdo localmente. O formulário e as tags externas dependem de rede e dos respectivos serviços.

O workflow publica os arquivos do site após um push na branch `main` ou execução manual. A conclusão e a URL de cada publicação podem ser acompanhadas em GitHub Actions.

## Projetos apresentados

Os links de demonstração e de código estão na seção de projetos. A disponibilidade do código-fonte e a licença devem ser verificadas em cada repositório; alguns projetos têm apenas o build público.

## Aplicativos no navegador

As versões web simples e os links das aplicações estão em [Aplicativos](https://mkbraion.github.io/apps/). As ferramentas locais salvam os dados somente no navegador e oferecem exportação quando indicada.
